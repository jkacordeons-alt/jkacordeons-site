📱 Configurar WhatsApp / Meta

Passo 1 — Token do Meta Business

Esse token permite que o sistema envie produtos para os seus catálogos automaticamente.

Gere em: Meta Business Suite → Configurações → Tokens de API do sistema. Precisa da permissão catalog_management.

Passo 2 — Hospedagem de fotos (imgBB)

O Meta exige que as fotos dos produtos estejam hospedadas em uma URL pública. O imgBB é gratuito e faz isso automaticamente.

Crie grátis em api.imgbb.com — é só criar uma conta e copiar a chave.

Passo 3 — Seus 3 catálogos

Coloque o nome (para você identificar) e o ID de cada catálogo. Encontre os IDs em Meta Commerce Manager → Catálogos → Configurações.
